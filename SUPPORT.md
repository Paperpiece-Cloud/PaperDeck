# Support

- Bugs and feature requests: [GitHub Issues](https://github.com/Paperpiece-Cloud/PaperDeck/issues)
- Questions and setup help: [GitHub Discussions](https://github.com/Paperpiece-Cloud/PaperDeck/discussions)
- Security reports: see [SECURITY.md](SECURITY.md)

When asking for help, include:

- PaperDeck version
- Windows version
- Display resolution and scale
- Player name and track for media issues
- Whether the app was installed or run from source
- Relevant logs/screenshots
